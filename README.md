## Development Philosophy

I believe a good data project isn't just about training a model.

It should answer three questions:

> **What happened?**
> **Why did it happen?**
> **What can we do about it?**

That's why I focus on combining:

**Clean Data + Reliable Analysis + Clear Visualization + Practical Modeling**
